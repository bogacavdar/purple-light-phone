# Purple Light · Mor Işık (telefon sürümü, v104)

Tek oyunculu, piksel sanatlı bir keşif ve hayatta kalma oyunu. Mor bir ışık eşini götürdü; Yıldızsız Ada'da bir taştan başlayıp onu arıyorsun.

**Oyna (telefon):** https://bogacavdar.github.io/purple-light-phone/ · bilgisayar: https://bogacavdar.github.io/purple-light/

iPhone'da Safari ile aç → Paylaş → **Ana Ekrana Ekle**: simgeden açınca tam ekran olur.

## Kontroller (masaüstü)
WASD yürü · E topla / konuş · H boş el (topla) · Boşluk vur · Q atıl · Shift koş · Tab elle yap · F ye · M harita · V kamp ateşi kur · N haritaya işaret koy · Esc menü

## Dosyalar
- `index.html` — oyunun kendisi (tek dosya, GitHub Pages bunu açar)
- `manifest.webmanifest`, `icon-*.png` — Ana Ekrana Ekle için
- `proje/` — geliştirme dosyaları: prototip, tarif verisi, devam notu, Playwright testleri

Kayıtlar her adreste ayrı tutulur. claude.ai sürümündeki kaydını taşımak için oyunda **Kayıtları dışa aktar** → kodu kopyala → buradaki sürümde **Kayıtları içe aktar**.
